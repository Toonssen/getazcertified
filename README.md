# getazcertified

Free, original practice questions for Azure certifications. **Coming soon** at
[getazcertified.com](https://getazcertified.com).

Based on [ghcertified](https://github.com/v-fidelusaleksander/ghcertified). Licensed under GPL-3.0.
Not affiliated with or endorsed by Microsoft.

## Contribute

Questions live in [`questions/`](questions) as Markdown, and you can add or improve them straight from your browser.
Start with [CONTRIBUTING.md](CONTRIBUTING.md), or
[report a problem with a question](https://github.com/Toonssen/getazcertified/issues/new?template=question-problem.yml)
(the **Report** link on each question on the site fills it in for you).

Security issues: see [SECURITY.md](SECURITY.md).
