# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Toonssen/getazcertified/security/advisories/new)
(Security tab → "Report a vulnerability"). Don't open a public issue or pull request for a security problem.

You can expect an acknowledgement within a few days. This is a static site without user accounts or a backend,
so the main areas of interest are the deploy pipeline (GitHub Actions), the published content and the HTTP headers.
